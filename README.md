# 🚀 Backend Learning Repository

A structured collection of backend development experiments, demos, and learning projects covering Node.js, Express.js, REST APIs, EJS templating, OOP in JavaScript, and database fundamentals.

---

## 📁 Project Structure

```
├── Database-Learning/       # Database concepts and hands-on practice
├── Delta-Demo/              # Demo Repo (Delta course)
├── EJSDir/                  # EJS templating engine examples
├── ExpressDir/              # Express.js fundamentals and routing
├── JS-OOPS/                 # Object-Oriented Programming in JavaScript
├── Learned-GET-POST/        # HTTP GET & POST request handling
├── REST/                    # RESTful API design and implementation
├── demo2/                   # Experimental demos
└── .gitignore
```

---

## 📚 Module Descriptions

### 🗄️ Database-Learning

Covers database concepts including CRUD operations, queries, and connecting databases to Node.js applications.

### ⚡ Delta-Demo

Just a demo repository.

### 🖼️ EJSDir

Hands-on examples using **Embedded JavaScript (EJS)** templating to render dynamic HTML pages from the server side.

### 🌐 ExpressDir

Fundamentals of the **Express.js** framework — routing, middleware, request/response handling, and server setup.

### 🧠 JS-OOPS

Exploration of **Object-Oriented Programming** concepts in JavaScript: classes, inheritance, encapsulation, and prototypes.

### 📡 Learned-GET-POST

Practice with **HTTP methods** — handling GET and POST requests, form data, and query parameters in Express.

### 🔗 REST

Building **RESTful APIs** with proper HTTP verbs (GET, POST, PUT, PATCH, DELETE) and route structuring.

### 🧪 demo2

Experimental Repo.

## 🚦 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- npm (comes with Node.js)

### Run any project

```bash
# Clone the repository
git clone https://github.com/AquillaRival/<repo-name>.git

# Navigate into a module
cd ExpressDir

# Install dependencies
npm install

# Start the server
node index.js
```

> Each directory may have its own `package.json` and entry point. Check the folder's individual README (if present) for specific instructions.
